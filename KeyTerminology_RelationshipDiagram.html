How the Terms Connect

The glossary defines each term on its own — this shows how they actually fit together, from a base image to a running container, with the scanning checkpoint covered in the next lesson.

The Chain
A base image is built up with layers to form a complete image. Before it ever reaches a registry, scanning tools get a chance to catch known vulnerabilities — the earlier this happens, the simpler the fix. The image then gets pushed to a registry for storage and distribution, pulled back down, and run as one or more containers. Click any box above for that term's definition in this context.

At Scale

In production, an orchestrator decides which host runs which container, and restarts or redistributes them as needed. Kubernetes is the dominant platform for this today — covered in full in Kubernetes Fundamentals.
